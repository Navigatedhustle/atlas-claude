## Atlas's own code

v2 additions written for this demo: the voice orb (`web/orb.js`, raw WebGL), the second-brain canvas (`web/brain.js`,
no d3), the sandbox (`atlas/sandbox.py`, `atlas/sandbox_boot.py`), the knowledge graph and document index
(`atlas/knowledge/`), Developer mode (`atlas/dev.py`) and the embedding server (`atlas/embed_server.py`).

`igpu_shim.c` (LD_PRELOAD shim so Magpie/NanoCodec find the GB10 integrated GPU) and everything in
`atlas/`, `web/`, `eval/`, `scripts/` was written for this demo.

## Data

All data is synthetic, generated by `python -m atlas.data.generate --seed 42`. Company, people, and
account names are fictional. v2 documents (board memos, QBR notes, policies, grant abstracts, guidelines) are also
synthetic: the base corpus is generated from the database and tool outputs (`atlas/knowledge/docs.py`), and "Feed the
brain" documents are written on this box by the local LLM from tool facts. Every document is labelled SYNTHETIC.
